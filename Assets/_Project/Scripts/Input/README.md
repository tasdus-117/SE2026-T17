PlayerInputHandler translates action callbacks into clamped MoveInput and consumable Jump/Punch/Interact press flags. Assign SmallArena.inputactions in the Inspector, or Configure it while inactive before its first enable. It owns a cloned action asset and clears state on disable. It is not attached to the placeholder Player prefab in Task 1.5. Consumers must drain button flags each gameplay update and reject ineligible actions without buffering; match gating, grounding, cooldowns, physics and collection belong to later components.
